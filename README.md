# 💰 Money Tracker

Money Tracker is a full-stack personal finance management application built to help users track their income and expenses efficiently. It provides an intuitive interface for recording transactions, organizing them into categories, and analyzing personal financial activity through clear summaries and reports.

## ✨ Features
- Record income and expense transactions
- Organize transactions by category
- View transaction history
- Financial summary dashboard
- Search and filter transactions
- Responsive user interface

## 🛠️ Tech Stack
- Next.js
- React
- TypeScript
- Tailwind Css
- Shadcn UI Component
- PostgreSQL
- Supabase
